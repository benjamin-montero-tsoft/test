Para ejecutar en local desde el workspace como Java Application la clase AppReporteCrediticio.java
(Run As - Run Configurations ... o Debug As - Debug Configurations ...), se debe agregar en la solapa de "Arguments"
en la seccion de "VM Arguments" lo siguiente:

-DOnlineRCredi.home=/properties

Con este argumento indicaremos que en "C:\properties\conf\" se encuentra el archivo OnlineRCredi.properties

Un ejemplo de OnlineRCredi.properties se encuentra en la carpeta bajadaAMDOCSMensual\conf de este modulo
